## 一、名稱＋副標（兩組，選一組）

| | A（推薦） | B |
|---|---|---|
| 名稱 | 瓜相：古書看面相 | 瓜相 面相古書對照 |
| 副標 | 掃臉量比例，對照麻衣相法原文 | 量不到就寫沒看，每條附出處 |
| 使用者會搜的詞 | 看面相、面相、古書、麻衣相法 | 面相、古書 |
| 差異化放在哪 | 副標講「真的量」和「有原文」 | 副標講「不湊結論」和「有出處」 |

推薦 A。「看面相」是一般人搜的說法，「麻衣相法」是對相書有興趣的人會打的書名，兩個都放進會被讀的欄位。副標同時講了瓜相跟其他面相 app 最不一樣的兩件事：真的量臉、附原文。

B 的副標比較有個性，「量不到就寫沒看」會讓人停下來看。代價是「沒看」「出處」沒人會搜，副標這一格等於只拿來被看懂、不拿來被搜到；「麻衣相法」要退到關鍵字欄位。

名稱的冒號備案（domi-aso-copy ❓8）：A 被退或你不想用冒號，改成「瓜相 古書看面相」。

上架指南第一關提過「瓜相」可能已經被別人用。建 app 時名稱填的是什麼，這裡要跟著改。【待定：後台實際的名稱】

## 二、關鍵字欄位

照你給的上限 100 bytes 寫（中文一個字 3 bytes），逗號分隔、不加空格。名稱、副標、類別（生活風格、娛樂）已有的詞不再放。

搭配 A：

```
相書,看相,相學,五官,臉型,十二宮,流年,命理,算命,神相全編,相面,五行,三停
```

搭配 B：

```
麻衣相法,相書,看相,五官,臉型,十二宮,流年,命理,算命,相學,相面,五行,三停
```

要你決定的一個詞：「算命」。上架指南說 app 定位是傳統文化解讀，描述和截圖我都沒用這個詞；關鍵字欄位不會顯示出來，放了能被搜到。你不想沾這個詞就刪掉，空出來的 7 bytes 換成「臉相」。

沒放的：手相（app 不看手相）、臉部分析（聽起來像醫美或健康）、AI（規則不准寫 AI 算命，「AI」單放也容易被組成那個意思）、競品名。

App Store Connect 說明寫的是 100 字元。如果後台實際是算字元不是 bytes，可以再加五、六個詞，到時候再補。

## 三、宣傳文字（170 字元內，不用送審就能改）

```
掃一次臉，看古書怎麼說你。臉的比例在手機上算，每一條結論都附古書原文、白話和出處，量不到的就寫「沒看」，告訴你為什麼。
```

上架初期沒有限時活動可放，先放這句。收費定案後如果有免費額度，可以改放這裡，但不寫價格。

## 四、描述

```
用 iPhone 的 Face ID 鏡頭量你臉的比例，對照麻衣相法這幾本古代相書，看古書怎麼說你。每一條都附原文和出處，量不到的就寫量不到。

瓜相是給對面相好奇、但不一定相信的人用的。報告上每一句都查得到是哪本書、哪一段寫的，你自己判斷要信多少。

【報告裡有什麼】
• 五行形：你的臉形比較接近古書說的哪一種
• 五官：眉、眼、鼻、口、耳，古書各怎麼說（耳朵掃不到，直接寫沒看）
• 三停：臉分上中下三段，古書怎麼看比例
• 十二宮：臉上十二個位置各管哪件事
• 流年：照你今年的年紀，古書看哪個部位

每一項標「相符」「不同」「介於中間」或「沒看」。點開看古書原文、白話翻譯和出處。

【量不到的就寫沒看】
耳朵被頭髮蓋住、某個點這次掃得不夠穩、你說眉毛紋過或鼻子動過，那一項就寫「沒看」和原因，不拿別的點硬湊一個結論。有瀏海也可以跳過拉髮際線，三停就不看，其他照常。

【問古書】
看完報告還有問題，可以問古書。回答由 Anthropic 的 Claude 產生，只能引用你這份報告，每段後面帶依據標籤，點一下就看到它引的是哪一條、古書原文怎麼寫。
第一次問之前會先問你同意。傳出去的只有文字：你的問題、前幾題問答、你填的簡介（生日只換算成年紀）、量測結果的文字整理。照片和臉部座標不傳。

【你的臉留在手機上】
• 相機畫面、臉部網格、深度資料只在掃描當下用來算比例，算完就丟
• 只留最正的那一張照片和量測數字，放在報告最上面
• 照片在手機鎖著時讀不到，不進 iCloud 備份
• 不用帳號、沒有廣告、不做使用者分析、不能上傳照片
• 設定裡按「清除所有資料」就全部刪掉

【使用前要知道】
• 只給滿 18 歲的人用，只能掃自己的臉
• 需要有 Face ID 的 iPhone
• 古書的說法沒有人驗證過，報告也不評價人品。不要拿它替你或別人做重大決定
```

- 結果：沒有命中

三欄重複檢查（名稱、副標、關鍵字的詞有沒有重複）：

- A：關鍵字裡跟名稱、副標重複的詞：無；欄位內重複：無
- B：關鍵字裡跟名稱、副標重複的詞：無；欄位內重複：無
- 類別「生活風格」「娛樂」的字都沒放進三欄

斷詞歧義（相連的詞換一種切法）：

- 「古書看面相」→「古書｜看面｜相」：「看面」不是常用詞，不會被組成別的意思
- 「看面相」→「看｜面相」，兩種都是要的意思
- 「麻衣相法原文」→「麻衣｜相法｜原文」：「相法」也是相學用語，沒有歧義
- 「量比例」→「量｜比例」：沒問題
- 「瓜相」→「瓜｜相」：搜「瓜」會跑出水果和遊戲，品牌組合要靠「瓜相」整個詞

審核紅線：沒有競品名、商標、價格、獎項、網址；描述沒放注音、沒用 ▌ 這類後台不收的符號，段落標題用【】、項目用 •。

## 八、自查（anti-ai-voice G 區）

- A 區禁用詞（擁抱、旅程、核心、關鍵、深入、值得、至關重要…）：程式搜過，沒有
- 對仗陷阱：描述第二段原本想寫「不是要你相信，而是…」，沒寫。「不拿別的點硬湊一個結論」是直述
- 開頭：描述第一句直接講用什麼量、對照什麼，刪掉就不知道這是什麼 app
- 結尾：最後是「使用前要知道」清點項目，沒有升華句
- 三段排比：「相符、不同、介於中間、沒看」是 app 的四種標籤，照原字列
- 破折號：0 個
- 粗體：0；emoji：0
- 聊天殘留：沒有
- 「我們」：描述裡 0 次
- 保護清單：Anthropic、Claude、麻衣相法、app 的按鈕和標籤字照 app 原文
